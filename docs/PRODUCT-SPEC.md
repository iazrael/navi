# Navi - 产品需求规格文档 (PRD)

> 版本：v0.1 | 日期：2026-05-07 | 状态：Approved

---

## 1. 产品概述

### 1.1 产品定义

**Navi** 是一款运行在 iPhone 上的离线 AI 个人助理应用。基于本地大语言模型，提供文本对话和拍照提问功能，所有数据完全在设备端处理，不依赖网络连接。

### 1.2 产品愿景

打造一个真正可用、好用的离线 AI 助手——不是技术 demo，而是能替代 ChatGPT 日常使用场景的生产力工具。

### 1.3 目标用户

- 对数据隐私敏感的用户
- 网络不稳定或经常离线的用户
- 想在移动端体验本地 AI 能力的技术爱好者

### 1.4 目标平台

- **设备**：iPhone 15 Pro（8GB RAM）及同等或更高配置
- **系统**：iOS 18.0+
- **最低性能要求**：8GB 内存，支持 Metal GPU

## 2. 核心功能

### 2.1 文本对话

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 用户与 AI 进行自然语言对话，支持多轮上下文 |

**验收标准**：

- 用户输入文本，AI 流式返回回复（逐字打字效果）
- 支持多轮对话，AI 自动理解上下文
- 对话历史本地持久化，app 重启后可继续
- 用户可创建多个独立对话会话
- 长回复自动滚动，用户可随时打断生成

### 2.2 拍照提问

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 用户拍照或选择相册图片，配合文字向 AI 提问 |

**验收标准**：

- 点击输入栏附件按钮 → 弹出选项：拍照 / 从相册选择
- 选中图片后在输入栏展示缩略图预览
- 用户输入问题后，图片 + 文本一起发送给 AI
- AI 回复中体现对图片内容的理解
- 发送的图片在聊天记录中展示缩略图

**典型使用场景**：
- 拍植物问名字和养护方法
- 拍商品问识别信息
- 拍错误信息/代码问解决方案
- 拍文档/菜单问翻译或解读

### 2.3 会话管理

| 项目 | 说明 |
|------|------|
| 优先级 | P0 |
| 描述 | 管理多个对话会话 |

**验收标准**：

- 首页展示对话列表，按最近更新排序
- 每条显示：标题（自动取首条消息前 20 字）、最后一条消息摘要、时间
- 左滑可删除对话
- 点击进入对话详情
- 右上角 "+" 新建对话
- 支持长按对话重命名

### 2.4 模型管理

| 项目 | 说明 |
|------|------|
| 优先级 | P1 |
| 描述 | 下载、切换、管理本地模型 |

**验收标准**：

- 模型列表页：展示可用模型，标注是否已下载、是否支持图片输入
- 下载功能：显示模型大小、下载进度、支持取消
- 模型切换：在设置中指定默认模型
- 存储管理：显示模型占用空间，支持删除已下载模型
- 首次使用时引导用户下载至少一个模型

**预支持的模型**：

| 模型 | 大小（约） | 多模态 | 说明 |
|------|-----------|--------|------|
| Gemma 3 1B IT | ~550MB | ✅ | 轻量级，响应快 |
| Gemma 3 4B IT | ~2GB | ✅ | 推荐默认，平衡性能和质量 |
| Gemma 4 E2B IT | ~2.4GB | ✅ | 较新，推理质量更好 |
| Qwen 2.5 1.5B | ~1.6GB | ❌ | 纯文本，中文能力强 |

### 2.5 设置

| 项目 | 说明 |
|------|------|
| 优先级 | P2 |
| 描述 | 应用偏好设置 |

**验收标准**：

- 推理参数（高级）：温度（Temperature）、Top-K、最大输出长度
- 外观：跟随系统 / 浅色 / 深色
- 关于页面：版本信息、开源许可

## 3. 用户体验要求

### 3.1 性能指标

| 指标 | 目标值 |
|------|--------|
| 冷启动（模型已加载） | < 1s |
| 首 token 延迟 | < 2s |
| 流式输出速度 | ≥ 15 tokens/s |
| 图片发送到首 token | < 5s |

### 3.2 交互规范

- 流式输出时底部显示"生成中..."状态 + 停止按钮
- 消息发送后输入栏清空，立即显示用户消息气泡
- AI 回复区域实时更新，自动滚动到底部
- 长按 AI 消息可复制文本
- 生成过程中不允许重复发送（输入栏禁用）

### 3.3 错误处理

- 模型未下载：提示下载，引导到模型管理页
- 内存不足：提示关闭其他 app 或换用更小的模型
- 生成中断：保留已生成内容，标记为不完整
- 模型加载失败：显示具体错误信息 + 重试按钮

---

## 4. 非功能需求

### 4.1 隐私 & 安全

- **零数据外传**：所有推理在设备端完成，不发送任何数据到服务器
- **不收集用户数据**：无 analytics、无 crash report 上报（第一版）
- 模型下载使用 HTTPS

### 4.2 存储管理

- 对话数据本地持久化存储
- 模型文件存储在 App Documents 目录
- 图片在消息中只保留压缩缩略图，不保留原图
- 提供"清除所有对话"和"清除缓存"功能

### 4.3 离线优先

- 核心功能完全离线可用
- 唯一需要网络的场景：下载模型文件
- 已下载模型后，可永久离线使用

---

## 5. 不做的事（V1 排除项）

| 功能 | 排除原因 |
|------|----------|
| 云端 API fallback | 违背离线定位 |
| 语音输入/输出 | 复杂度高，V2 考虑 |
| Agent / 工具调用 | 模型能力有限，体验不佳 |
| 实时摄像头对话 | 需要持续推理，性能压力大 |
| 多用户 / 账号体系 | 个人工具不需要 |
| iPad / Mac 适配 | 先聚焦 iPhone |
| iCloud 同步 | 离线优先，暂不考虑 |
| Widget / 快捷指令 | V2 考虑 |

## 6. 成功指标

- [ ] 能在 iPhone 15 Pro 上流畅运行 Gemma 3 4B IT 模型
- [ ] 文本对话体验流畅，流式输出无明显卡顿
- [ ] 拍照提问能正确识别图片内容并给出相关回答
- [ ] 完全断网状态下所有功能正常使用
- [ ] 从打开 app 到开始对话 < 3s（模型已加载）
